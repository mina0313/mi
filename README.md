# 미얀마 사무실 — 업무 자료

미얀마 사무실에서 쓰는 근무 수칙과 마케팅 교육 자료입니다.

## 보기

**https://<계정>.github.io/<저장소>/** ← Pages 켜면 이 주소로 열립니다

## 구성

| 폴더 | 내용 |
|---|---|
| `근무수칙/` | 전 직원 공통 근무 수칙 |
| `교육자료/` | 마케팅팀 교육 교안(DAY 1~8)·교육생용 자료·양식 |

## ⚠️ 계정 정보는 이 저장소에 없습니다

공개 저장소이므로 **아이디·비밀번호·시트 주소를 넣지 않습니다.**
문서에 `🔒` 표시가 있는 곳의 주소는 `계정시트.xlsx`와 구글 「계정 관리 시트」에 있습니다.

## 수정하는 방법

1. 원본은 바탕화면 `미얀마마케터_현지교육\` · `미얀마사무실_근무수칙\` 에 있습니다
2. 원본을 고친 뒤 `_publish.py` 를 실행하면 이 폴더가 다시 만들어집니다
   - 계정 정보를 자동으로 지우고, **하나라도 남아 있으면 빌드를 중단**합니다
3. `git add -A && git commit -m "수정 내용" && git push`

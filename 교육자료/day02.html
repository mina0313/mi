DAY 2 · 9월 17일 (목)

네이버 이해 + 통검표 읽는 법

검색 화면이 어떻게 생겼는지 보고, 그 화면이 표에 어떻게 적혀 있는지 안다

오늘의 목표

  1. 네이버 검색 결과가 영역별로 나뉘어 있다는 걸 눈으로 확인한다
  2. 광고 자리와 우리가 노리는 자리를 구분한다
  3. 통검표의 칸이 무슨 뜻인지 알고, 통검링크로 화면과 대조한다
오늘 두 가지를 붙여서 가르칩니다

오전에 화면을 보고, 오후에 그 화면이 표(통검표)에 어떻게 적혀 있는지 봅니다. 둘을 따로 배우면 연결이 안 됩니다. 「블로그 영역이 위에 크게 나온다 = 블로그 등급이 높다」 — 이 한 줄이 오늘의 전부입니다.

진행 흐름

  1. 네이버는 구글과 뭐가 다른가같은 키워드를 두 곳에 검색해 화면 비교
  2. 영역 이름 익히기화면을 위에서 아래로 내리며 순서대로 이름 부르기
  3. 광고 vs 자연 노출파워링크 표시 찾기 — 여기가 제일 많이 틀립니다
  4. 키워드 3~4개 화면 비교왜 화면이 다른지 각자 말하기
  5. 통검표 열기내 브랜드 통합시트 → 첫 탭. 칸 이름부터 하나씩
  6. ★ 통검링크 눌러 화면과 대조표만 보면 이해가 안 됩니다. 눌러야 합니다
  7. 정리 · 피드백한 명씩 자기 키워드 화면을 설명하게 함

강의 노트 — 앞부분: 네이버 화면

1. 네이버는 「영역으로 나눠서」 보여준다

구글은 링크 목록 하나를 쭉 보여주지만, 네이버는 블로그는 블로그끼리 / 카페는 카페끼리 묶어서 보여줍니다. 그리고 어떤 묶음을 위에 올릴지는 키워드마다 다릅니다.

이렇게 말해보세요

"네이버는 답을 한 줄로 주지 않고, 답이 있을 만한 서랍을 순서대로 열어줍니다. 물건을 사려는 사람에겐 쇼핑 서랍을 먼저 열고, 방법을 알고 싶은 사람에겐 블로그 서랍을 먼저 엽니다. 우리 글은 블로그 서랍에 들어 있습니다. 그러니까 블로그 서랍이 위에 열리는 키워드를 골라야 합니다."

→ 이 이름들이 그대로 통검표의 컬럼 이름입니다 (카페 · 블로그 · 지식인 · 언론).

2. 광고와 우리 자리는 다르다

가장 많이 하는 착각

맨 위에 있는 업체를 "1등 블로그"라고 생각합니다. 아닙니다. 맨 위는 대부분 광고(파워링크)이고 돈을 내면 올라갑니다. 화면에서 「광고」 표시를 직접 찾아 손가락으로 짚게 하세요.

3. 키워드가 다르면 화면이 다르다

4. 볼 때 지킬 것

  • 애니데스크로 한국 컴퓨터에서 본다 — 접속 위치에 따라 결과가 달라짐
  • 시크릿 창으로 본다 — 내 기록 때문에 왜곡되는 걸 막기 위해
  • PC와 모바일 둘 다 — 실제 고객은 모바일이 더 많음

강의 노트 — 뒷부분: 통검표

5. 통검표가 뭔가

통검 = 네이버 통합검색. 키워드 하나를 검색했을 때 나오는 화면을 조사해서, 「이 키워드는 어느 영역에서 노려볼 만한가」를 등급으로 적어둔 표입니다.

새로 만드는 게 아닙니다

브랜드마다 「OO 통합시트」가 이미 있고, 그 첫 탭이 「바이럴 통검표」입니다. 오늘은 여는 법과 읽는 법만 배웁니다.

「구조를 바꿔야 할 것 같다」는 생각이 들면 그때가 멈춰야 할 때라고 가르치세요 — 손대지 말고 담당자에게 묻기.
첫날 실수가 제일 많이 나오는 지점입니다. 넘어가지 말고 한 명씩 대답을 받으세요.

7. 등급 5단계

등급뜻

미포함그 영역이 화면에 아예 안 나온다
「미포함」을 꼭 짚어주세요

블로그가 미포함이면, 그 키워드는 블로그 글을 아무리 잘 써도 화면에 안 나옵니다. 검색량이 아무리 커도 우리가 쓸 키워드가 아닙니다. 여기서 헛수고가 제일 많이 생깁니다.

8. 통검링크를 반드시 눌러보게 하세요

  1. 통검링크 클릭 → 네이버 검색 결과 화면이 열린다
  2. 화면을 내리며 어떤 영역이 몇 번째에 나오는지 본다
  3. 표의 등급과 대조한다 — 「블로그 A+」면 화면에서 블로그가 위에 있어야 맞다
  4. 안 맞으면 네이버가 화면을 바꾼 것일 수 있습니다 → 담당자에게 보고
표가 아니라 오늘 화면이 맞습니다

통검표는 조사한 날짜 기준입니다. 오늘 눌러보면 다를 수 있습니다. 다르면 회사 시트를 고치지 말고 메모로 보고하게 하세요.

오늘 하는 일

별도 양식 없음. 화면과 회사 통합시트를 직접 열어서 진행합니다.

  1. 내 브랜드 키워드 3개를 검색한다 (고정 IP + 시크릿 창)
  2. 각 화면에서 영역 순서를 위에서 아래로 소리 내어 읽는다
  3. 광고(파워링크)를 손가락으로 짚는다
  4. 내 브랜드 통합시트를 열어 통검표 탭을 찾는다
  5. 키워드 10개의 통검링크를 하나씩 눌러본다
  6. 표의 등급과 화면이 맞는지 대조하고, 안 맞는 3개를 메모해서 담당자에게 보고한다

DAY 1 · 9월 16일 (수) · 교육생 첫 출근일

오리엔테이션과 업무 환경

우리가 누구인지, 무슨 일을 하는지, 그 일을 하려면 컴퓨터에 뭐가 있어야 하는지

오늘의 목표

  1. 우리 회사 브랜드 구조를 알고, 자기 브랜드가 파는 것과 안 파는 것을 자기 말로 설명할 수 있다
  2. 애니데스크로 한국 컴퓨터에 접속해서 네이버 작업을 할 수 있다
  3. 애니데스크로 한국 컴퓨터에 접속할 수 있고, 내 블로그를 확인했다

진행 흐름

  1. 서로 소개 + 8일 동안 할 일 안내전체 일정표를 띄우고 "마지막 날엔 혼자 글 한 편을 올리게 된다"를 먼저 말해주기
  2. ★ 교육생용 자료 배포 + 근무 수칙 공지교육생용 폴더를 넘기고, 근무 수칙을 인쇄해서 같이 읽기
  3. 우리 회사 브랜드 알기계열 구조를 보여주고, 배정 브랜드 홈페이지에서 파는 것 / 안 파는 것 적기
  4. 마케터가 하는 일 (5단계)키워드 → 원고 → 이미지 → 발행 → 확인·보고
  5. ★ 애니데스크 — 한국 컴퓨터 접속지금의 기본 작업 방식. 왜 이렇게 하는지 설명 후 실제로 접속시키기
  6. 고정 IP 설명 (설치까지만)당분간 안 씁니다 — IP 안정되면 돌아갈 수 있게 개념과 설치만
  7. 네이버 계정 로그인 + 내 블로그 확인이미 운영 중인 블로그를 이어받습니다. 개설 아님 — 연습 글 발행 금지
  8. 정리 · 질문 · 내일 예고오늘 배운 용어를 각자 노트에 정리하게 함

강의 노트

1. 우리는 어떤 일을 하는가

"블로그 글쓰기"가 목적이 아니라, 검색하는 사람이 우리 회사를 찾게 만드는 것이 목적입니다. 이 순서로 설명하세요.

단계하는 일언제 배우나
① 키워드 고르기통검표를 보고 우리 고객이 쓸 말을 고른다DAY 2·3
② 원고 쓰기그 키워드로 검색한 사람이 궁금해할 내용을 글로 쓴다DAY 4·5
③ 이미지 만들기회사 사진 폴더에서 사진 고르기 + 카드뉴스 제작DAY 6·7
④ 발행네이버 블로그에 올린다DAY 5부터 계속
⑤ 확인·보고검색해서 보이는지 확인하고 담당자에게 보고한다매 발행마다

2. 담당 브랜드 — 주력 6개

브랜드 전체 정리는 따로 있습니다

→ 담당 브랜드 정리 · 브랜드별 하는 일 · 사이트 · 대표 키워드 · 표기 규칙. 수업 전에 트레이너가 먼저 읽고, 교육생에게는 배정된 브랜드 부분만 발췌해서 주세요.

6개를 다 설명하되, 담당은 1인 1개입니다.

★ 이번 배정 — 4명 / 1인 1브랜드

담당 — 퍼스트디자인 · 하오디자인 · 하오스튜디오 · 윈차이나
이번엔 미배정 — 하오팩토리 · 레드트랜스 (설명만 합니다)

미배정 브랜드도 설명은 합니다. 나중에 담당이 바뀌거나 늘어날 수 있고, 겹치는 키워드를 알아야 남의 자리를 뺏지 않기 때문입니다.

교안 예시에 하오팩토리·레드트랜스가 나오면 「지금은 아무도 안 맡지만 이런 브랜드도 있다」로 설명하면 됩니다.

계열브랜드
하오 하오디자인(인쇄) · 하오스튜디오(촬영) · 하오팩토리(조형물)
퍼스트 퍼스트디자인(인쇄)
인증·번역 레드트랜스(번역·아포스티유) · 윈차이나(중국비자·아포스티유)
글에는 「홍보성 / 정보성」 두 방향이 있습니다

브랜드를 나누는 게 아니라 글을 나눕니다. 첫날엔 이 정도만 알려주고, 자세한 건 DAY 3에서 키워드를 고를 때 설명합니다. → 브랜드 정리

※ 회사에는 이 외에도 퍼스트스튜디오·퍼스트마케팅컴퍼니·하오커뮤니케이션·하오웹·퍼스트로고가 있습니다. 구조는 알려주되 작업은 위 6개로만 합니다. → 브랜드 정리

배정 브랜드 홈페이지 읽고 표 채우기

홈페이지를 직접 열어 읽고 채우게 하세요. 설명을 먼저 해주면 안 봅니다.

내 브랜드우리가 파는 것우리가 안 파는 것 / 헷갈리는 것
(배정 브랜드)(교육생이 직접 적기)(교육생이 직접 적기)
여기서 시간을 아끼지 마세요

브랜드를 잘못 이해한 채로 넘어가면 DAY 5부터 나오는 원고가 전부 어긋납니다. "우리가 안 하는 서비스"를 적게 하는 게 특히 중요합니다 — 나중에 없는 서비스를 광고하는 글이 나오는 걸 막아줍니다.

인쇄는 하오디자인과 퍼스트디자인 양쪽에 다 있습니다. "내 브랜드가 어느 쪽인지"를 헷갈리면 남의 회사 홍보를 하게 됩니다.

3. ★ 애니데스크 — 지금의 기본 작업 방식

먼저 「왜」를 설명하세요 — 이유를 모르면 안 지킵니다

원래는 고정 IP를 켜고 각자 컴퓨터에서 작업하는 방식이었습니다. 그런데 지금 네이버 서버가 불안정해서, 고정 IP로 제대로 접속해도 보호조치가 걸려 계정이 잠기는 일이 계속 생기고 있습니다.

그래서 당분간은 애니데스크로 한국 컴퓨터에 접속해서, 그 컴퓨터로 네이버 작업을 합니다. 한국에 있는 진짜 컴퓨터에서 하는 작업이라 네이버가 이상하게 보지 않습니다.

한시적인 조치라는 것도 같이 말해주세요. IP가 안정되면 원래대로 고정 IP를 씁니다 — 다만 그 시점은 담당자가 판단해서 알려줍니다.

방향을 정확히 — 미얀마 컴퓨터 → 한국 컴퓨터 접속 → 한국 컴퓨터로 작업. 내 컴퓨터를 남이 보는 게 아니라 내가 한국 컴퓨터를 빌려 쓰는 것입니다.

교육생에게는 매뉴얼을 그대로 주세요

→ 애니데스크 매뉴얼 (배포용) · 접속 방법, 시크릿 창, 끝낼 때 순서, 안 될 때 대처. 아래는 수업에서 짚을 요점입니다.

  1. anydesk.com 에서 내려받아 설치
  2. 담당자에게 내 한국 컴퓨터 9자리 주소 + 비밀번호를 받아 적는다 (사람마다 쓸 컴퓨터가 정해져 있습니다)
  3. 애니데스크 입력칸에 그 주소를 넣고 연결 → 비밀번호 입력
  4. 한국 컴퓨터 화면이 뜨면 시크릿 창(Ctrl+Shift+N)을 열고 거기서 로그인
  5. 작업이 끝나면 로그아웃 → 시크릿 창 닫기 → 연결 종료
첫날에 반드시 못 박을 것
  • 네이버 작업은 전부 한국 컴퓨터 안에서. 미얀마 컴퓨터로 그냥 로그인하지 않습니다 — 「잠깐 확인만」도 안 됩니다
  • 시크릿 창에서 로그인 — 다음에 그 컴퓨터를 쓰는 사람에게 내 계정이 남으면 안 됩니다
  • 한국 컴퓨터에서 내 일만 합니다. 다른 파일·설정을 건드리지 않습니다
  • 나에게 배정된 컴퓨터만 씁니다. 남의 주소로 접속하지 않습니다
  • 접속·종료를 매번 보고할 필요는 없습니다 — 1인 1대라 서로 부딪히지 않습니다. 연결이 안 될 때만 바이버로 알립니다
첫날에 전원 한 번씩 실제로 접속시키세요

이게 DAY 1의 최우선 과제입니다. 여기서 안 되면 그 사람은 이후 아무 작업도 못 합니다. 로그인 → 로그아웃 → 연결 종료까지 한 바퀴를 손에 익히게 하세요.

한국 컴퓨터 주소·비밀번호는 「계정시트.xlsx → 애니데스크」 시트에 정리되어 있습니다.

4. 고정 IP — 개념과 설치까지만

당분간은 쓰지 않습니다. 그래도 설명은 해두세요

IP가 안정되면 고정 IP 방식으로 돌아갑니다. 그때 처음부터 가르치면 늦으니, 첫날에 개념 설명 + 설치까지만 해둡니다.

「IP가 안정돼서 담당자가 쓰라고 할 때까지는 안 쓴다」를 분명히 말해주세요. 혼자 판단해서 고정 IP로 작업하면 계정이 잠깁니다.

교육생에게는 매뉴얼을 그대로 주세요

→ 고정 IP 접속 매뉴얼 (배포용) · 접속 순서부터 내 IP 확인법, 안 될 때 대처까지.

설명할 요점은 3가지입니다.

  • 네이버는 한국에서 쓰는 서비스입니다. 해외 IP로 로그인하면 보안 확인이 뜨거나 로그인이 막힐 수 있습니다.
  • 같은 계정이 오늘은 한국, 내일은 다른 나라 IP로 번갈아 접속되면 이상 접속으로 판단됩니다.
  • 검색 결과도 접속 위치에 따라 다르게 보입니다. 한국 사람이 보는 화면을 봐야 판단이 맞습니다.
우리는 「고정 IP」를 씁니다 — 사람마다 IP가 다릅니다

아무 VPN이나 켜는 게 아니라, 회사가 계약한 한국 고정 IP를 사람별로 배정받아 씁니다. 그래서 확인할 것은 「한국인가」가 아니라 「내 IP 숫자와 같은가」입니다.

※ 기존 목록(____________~11)은 베트남 팀 것입니다. 미얀마 인원용은 담당자가 별도로 배정합니다.

5. 네이버 계정과 내 블로그 확인

계정은 준비되어 있습니다 — 문제는 「첫 로그인」입니다

계정을 새로 만들 일은 없습니다. 대신 미얀마에서 처음 로그인할 때 네이버가 추가 인증을 요구할 수 있습니다. (새 기기·해외 접속으로 판단하기 때문)

  • 반드시 애니데스크로 한국 컴퓨터에 접속한 뒤, 그 안에서 시크릿 창으로 로그인합니다
  • 인증 요구가 뜨면 교육생이 혼자 누르지 않게 하세요 — 잘못 누르면 계정이 잠깁니다
  • 인증 문자·메일을 받을 수 있는 담당자가 옆에 붙어서 같이 진행합니다
  • 계정이 잠기면 그 사람은 교육 내내 아무것도 못 합니다. 여기가 첫날의 최대 고비입니다
★ 블로그를 새로 만드는 게 아닙니다 — 이미 있는 블로그를 이어받습니다

브랜드마다 이미 운영 중인 블로그가 있고, 「지수」(준최3 · 준최5 · 최적3 …)가 쌓여 있습니다. 이 지수는 몇 년에 걸쳐 만들어진 회사 자산이고, 한 번 떨어지면 되돌리기 매우 어렵습니다.

그래서 연습 글을 실제 블로그에 발행하면 안 됩니다. 에디터 연습은 임시저장까지만 하고 반드시 삭제하세요. 실제 발행은 DAY 7에 검수받은 원고로 처음 합니다.

  1. 배정받은 계정으로 로그인 (반드시 고정 IP 연결 + IP 확인 후)
  2. 내 블로그 주소를 열어 어떤 글이 올라와 있는지 훑어본다 — 앞으로 이 톤을 이어갑니다
  3. 카테고리 구성 확인 (새로 만들지 말고 있는 것을 파악)
  4. 구글 계정 관리 시트에서 내 블로그의 지수를 확인하고 적어둔다
  5. 에디터 연습: 아무 내용이나 써보고 임시저장 → 삭제. 발행 버튼은 누르지 않습니다
「지수」를 여기서 한 번 설명해주세요

네이버 블로그에는 눈에 보이지 않는 등급이 있습니다. 같은 글을 써도 등급이 높은 블로그가 더 위에 올라갑니다. 준최2 → 준최5 → 최적 순으로 좋습니다.
등급은 블로그연구소에서 확인합니다 (아이디: 계정시트 「참고링크」 시트).
남의 글 복사, 하루에 몰아쓰기, 광고성 글만 쓰기 — 이런 걸 하면 등급이 떨어집니다.

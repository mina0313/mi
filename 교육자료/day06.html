DAY 6 · 9월 22일 (화) · ★ 2편 발행

발행까지 전 과정 + 1편 혼자

발행하는 법을 배워 전 과정을 완성하고, 곧바로 1편을 처음부터 혼자 해본다

★ 오늘도 처음부터 — 매일 같은 흐름을 반복합니다

오늘 새로 배우는 것은 「발행」입니다 — 이것으로 전 과정이 끝납니다

앞 단계는 어제까지 배운 것입니다. 설명은 하지 않고 바로 시켜보세요. 매일 처음부터 돌려야 손에 익고, 마지막 날에 혼자 할 수 있게 됩니다.

오늘로 배울 건 다 배웁니다. 그래서 오후에는 1편을 처음부터 혼자 해보게 합니다.

순서단계오늘
①통검표 확인 및 수정복습 — DAY 2에 배움
②키워드 선정 + 제목복습 — DAY 3에 배움
③원고 쓰기 (생성기 3줄 → 다듬기)복습 — DAY 4에 배움
④사진 고르기 + 카드뉴스복습 — DAY 5에 배움
⑤발행 → 확인 → 보고★ 오늘 새로 배웁니다

오늘의 목표

  1. ★ 어제 만든 것을 실제로 발행하고 확인·보고까지 한다
  2. 발행 전 중간 보고 습관을 만든다
  3. ★★ 1편을 키워드부터 발행까지 혼자 한 바퀴 돌려본다
오늘로 배울 건 다 배웁니다

오전에 발행하는 법을 배우면 ①~⑤가 전부 채워집니다.
그래서 오후에는 바로 1편을 처음부터 혼자 해보게 합니다 — 내일부터 하루 2편을 하려면 오늘 한 바퀴를 혼자 돌아봐야 합니다.

오늘 발행 = 2편 (어제 것 1편 + 오늘 혼자 만든 1편)

오늘 반드시 발행합니다

카드뉴스를 완벽하게 만드느라 발행을 미루지 마세요. 못생겨도 올립니다. 디자인이 마음에 안 들어도 오늘 안에 발행합니다.

장수를 줄여서 시간을 벌지는 않습니다. 문단 수만큼은 만들어야 합니다 — 대신 템플릿에 문장만 갈아 끼워서 빠르게 만드세요.

진행 흐름

  1. 어제 만든 것 점검원고 + 카드뉴스가 발행 가능한 상태인지
  2. 블로그에 넣기내보내기 → 순서대로 삽입 → 모바일 확인
  3. ★ 중간 보고발행 전에 담당자에게 보내 확인받는 습관
  4. ★ 발행 (1편째)발행 → 확인 5단계 → 보고. 여기까지가 오전
  5. ★★ 1편 혼자 — 처음부터통검표 → 키워드 → 원고 → 카드뉴스 → 발행. 도와주지 않는다
  6. 중간 점검 1회키워드 선정까지만 확인 — 잘못 고르면 뒤가 전부 헛일
  7. 발행 (2편째)간격을 두고 발행 → 확인 → 보고
  8. 피드백혼자 하면서 어디서 막혔는지 한 명씩 듣기

강의 노트 — 앞부분: 어제 만든 것 점검

카드뉴스는 어제 배웠습니다 — 오늘은 확인만

어제 만든 원고 + 카드뉴스가 올릴 수 있는 상태인지만 봅니다. 다시 가르치지 마세요. 못 끝낸 사람만 오전에 마무리시킵니다.

확인보는 것
원고검수표 통과했는가 · 확인 안 된 숫자가 남아 있지 않은가
카드뉴스 장수원고 문단 수와 맞는가 (모자라면 채우게 합니다)
워터마크유료 요소가 섞이지 않았는가 — 있으면 그 요소만 교체
파일명 · 순서날짜_브랜드명_메인키워드 규칙대로인가 · 장 번호 순서가 맞는가
「제목 없는 디자인」 같은 자동 이름이 남아 있으면 그 자리에서 고치게 하세요
사진 출처★ 검색해서 가져온 사진이 없는가 — 한 명씩 물어보세요

강의 노트 — 발행

1. 발행 전 확인 (매번)

  • 애니데스크로 한국 컴퓨터에 접속한 상태인가 → 시크릿 창으로 로그인했는가
  • 올바른 계정으로 로그인했는가
  • 원고 · 사진 · 카드뉴스 세 가지가 다 준비되어 있는가

2. 스마트에디터 기본

요소이렇게 씁니다
제목정한 제목 그대로. 발행 후엔 가급적 안 바꿉니다
본문 문단3~4줄마다 줄 띄우기. 모바일에서 벽처럼 보이면 안 읽습니다
소제목제목 스타일로 글자 크기 구분. 5개 소제목 = 5칸 목차
사진소제목마다 1장 정도. 첫 사진이 대표 이미지
카드뉴스도입부 다음 또는 마무리 앞에 순서대로 삽입. 순서가 섞이면 말이 안 됩니다
링크회사 홈페이지 링크는 1~2개면 충분
태그5~10개. 관련 없는 인기 태그를 붙이지 않습니다

3. 발행 시각 — 정해진 시각은 없습니다

완성되면 올리면 됩니다. 브랜드별로 정해진 시각은 없습니다.

★ 다만 여러 편을 한꺼번에 올리지 마세요

앞으로 하루 2편을 올리게 됩니다. 그걸 한 번에 몰아서 올리면 계정이 위험해집니다. 사람이 쓴 게 아니라 기계가 뿌린 것처럼 보이기 때문입니다.

편과 편 사이에 시간 간격을 두세요. 최소 1~2시간은 띄웁니다.

예약 발행을 쓰면 편합니다

글을 다 써놓고 예약 발행으로 시간을 나눠서 걸어두면, 하루 종일 신경 쓰지 않아도 알아서 나갑니다.
예: 4편을 다 만들었으면 → 2시간씩 간격을 두고 예약

예약 시간은 네이버 화면의 시간(한국 기준)으로 입력됩니다. 한국이 미얀마보다 2시간 30분 빠르니, 내 시계로 오후 3시에 나가게 하려면 네이버에는 17:30을 넣습니다.

4. ★ 발행 전에 — 초반에는 반드시 중간 보고

사진·카드뉴스까지 완성되면 먼저 보여줍니다

일이 손에 익기 전까지는 바로 발행하지 않습니다. 원고 + 사진 + 카드뉴스가 완성된 시점에 담당자에게 보내서 확인을 받고, OK를 받으면 발행합니다.

보낼 때 3가지를 같이 — ① 제목과 키워드 ② 원고 ③ 카드뉴스 이미지 전체

익숙해지면 담당자가 「이제 바로 발행해도 된다」고 알려줍니다. 그전까지는 매번 확인받습니다.

올리고 나서 고치는 것보다 올리기 전에 확인받는 게 빠릅니다. 잘못 올라간 글은 지워도 검색에 흔적이 남습니다.

5. 발행 후 확인 5단계

확인보는 것
①PC 화면이미지·카드뉴스가 깨지지 않았나, 순서가 맞나
②모바일 화면휴대폰으로 직접 열기 — 카드뉴스 글자가 읽히는지 특히 확인
③글 주소(URL)복사해서 보고서에 기록
④검색 확인제목 그대로 검색. 키워드 노출은 시간이 걸립니다
⑤보고담당자에게 링크와 함께

6. 하면 안 되는 것 — 계정이 위험해집니다

  • 다른 사람 글 복사 — 한 문단이라도 안 됩니다
  • 구글·네이버에서 검색한 사진 사용 — 카드뉴스에도, 본문에도 절대 금지
  • 같은 글을 여러 블로그에 그대로 올리기
  • 여러 편을 한꺼번에 올리기 — 간격을 두세요 (최소 1~2시간)
  • 링크·연락처 도배 / 키워드 부자연스럽게 반복
  • 미얀마 컴퓨터에서 그냥 네이버 로그인 — 실제로 보호조치를 받은 계정이 있습니다 (2026-03-10). 지금은 애니데스크로 한국 컴퓨터에 접속해서 작업합니다

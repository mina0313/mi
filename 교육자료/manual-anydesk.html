애니데스크 — 한국 컴퓨터 원격 사용

당분간 — IP가 안정될 때까지, 한국 컴퓨터에 접속해서 그 컴퓨터로 네이버 작업을 합니다

이게 뭔가요?

애니데스크는 멀리 있는 컴퓨터를 내 화면에서 조종하는 프로그램입니다.

우리는 이렇게 씁니다

미얀마 컴퓨터 → 한국 컴퓨터에 접속 → 한국 컴퓨터로 네이버 작업

내 컴퓨터를 남이 보는 게 아니라, 내가 한국 컴퓨터를 빌려 쓰는 것입니다. 화면만 미얀마에서 보고, 실제 작업은 한국 컴퓨터 안에서 일어납니다.

★ 왜 이 방법을 쓰나요? — 이유를 알아야 합니다

지금은 고정 IP만으로는 부족합니다

원래는 고정 IP를 켜고 내 컴퓨터에서 작업하는 방식이었습니다. 그런데 지금 네이버 서버가 불안정해서, 고정 IP로 제대로 접속해도 보호조치가 걸려 계정이 잠기는 일이 계속 생기고 있습니다.

계정이 한 번 잠기면 푸는 데 오래 걸리고, 그동안 그 블로그는 아무것도 못 올립니다.

그래서 당분간은 애니데스크로 한국 컴퓨터에 접속해서, 그 컴퓨터로 네이버 작업을 합니다. 한국에 있는 진짜 컴퓨터에서 하는 작업이라 네이버가 이상하게 보지 않습니다.

이건 한시적인 방법입니다. IP가 안정되면 원래대로 고정 IP를 쓰게 됩니다 — 그때는 담당자가 알려줍니다. 그전까지는 계속 이 방법으로 하세요.

★ 당분간 (지금)
IP가 안정될 때까지		 네이버 작업은 전부 애니데스크로 한국 컴퓨터에 접속해서 합니다
IP가 안정된 뒤 담당자가 「이제 고정 IP로 돌아가도 된다」고 알려줍니다. 그 연락을 받기 전까지는 계속 애니데스크로 → 고정 IP 매뉴얼
언제까지 하나요?

정해진 날짜는 없습니다. 네이버 쪽 상황이 나아져서 IP가 안정되면 바뀝니다. 내가 판단해서 바꾸는 게 아니라, 담당자가 알려주면 바꿉니다.

이것만은 절대

미얀마 컴퓨터에서 그냥 네이버에 로그인하지 마세요. 「잠깐 확인만」도 안 됩니다. 접속 기록이 그대로 남습니다.

1. 설치하기 (처음 한 번만)

  1. 인터넷 주소창에 anydesk.com 입력
  2. 다운로드(Download) → Windows용 파일이 내려받아집니다
  3. 내려받은 파일을 실행 → 「설치(Install)」를 눌러 설치
  4. 「이 앱이 변경할 수 있도록 허용하시겠습니까?」 창이 뜨면 예
주의

반드시 anydesk.com 공식 사이트에서만 받으세요.
설치가 막히면(관리자 권한 없음) 혼자 해결하지 말고 담당자에게 알려주세요.

2. 내가 접속할 한국 컴퓨터 정보

한국에 컴퓨터가 여러 대 준비되어 있습니다

한국에 4~5대의 컴퓨터를 미리 켜두고 애니데스크를 설치해 두었습니다. 사람마다 쓸 컴퓨터가 정해져 있습니다. 내 컴퓨터 주소만 쓰면 됩니다.

담당자가 매번 수락해주지 않아도 바로 접속됩니다. (무인 접속으로 설정되어 있습니다)

담당자에게 받아서 여기에 적어두세요. 매번 쓰게 됩니다.

내 한국 컴퓨터 주소 (9자리)_____ _____ _____
접속 비밀번호____________ (담당자에게 받기)
문제 생기면 연락____________ (바이버)

전체 목록은 계정시트 「애니데스크」 시트에 있습니다.

3. 한국 컴퓨터에 접속하기

  1. 애니데스크 실행아침에 출근하면 가장 먼저
  2. 내 한국 컴퓨터 주소를 입력한다화면 위쪽 「원격 데스크」 입력칸에 9자리 주소
  3. 연결 버튼을 누른다비밀번호를 물어보면 받은 비밀번호 입력
  4. 한국 컴퓨터 화면이 뜬다이제부터 보이는 화면은 한국 컴퓨터입니다
  5. ★ 시크릿 창을 열고 로그인그 컴퓨터에 내 계정 기록이 남지 않게. 아래 4번
  6. 작업한다네이버 검색·글쓰기·발행 모두 이 화면 안에서
  7. 끝나면 로그아웃 → 시크릿 창 닫기 → 연결 종료순서대로. 아래 5번
접속한다고 매번 보고하지 않아도 됩니다

컴퓨터가 사람별로 배정되어 있어서 서로 부딪히지 않습니다. 그냥 접속해서 쓰면 됩니다. 연결이 안 될 때만 담당자에게 알리세요.

[스크린샷 넣을 자리 — 주소 입력칸 / 연결된 화면]

4. ★ 한국 컴퓨터에서는 「시크릿 창」으로 로그인합니다

이유가 분명합니다

한국 컴퓨터는 여러 사람이 돌아가며 쓰는 컴퓨터입니다. 평소 창에서 로그인하면 내 아이디와 비밀번호가 그 컴퓨터에 저장되고, 다음에 쓰는 사람 화면에 내 계정이 그대로 열려 있게 됩니다.

시크릿 창에서 로그인하면 창을 닫는 순간 기록이 사라집니다.

여는 방법

브라우저단축키
크롬 (Chrome)Ctrl + Shift + N
엣지 (Edge)Ctrl + Shift + N
파이어폭스Ctrl + Shift + P

창이 검은색/어두운 색으로 바뀌면 시크릿 창입니다.

주의
  • 시크릿 창은 닫으면 로그인이 풀립니다. 작업 중에 실수로 닫지 마세요
  • 글을 쓰는 중이라면 임시저장을 자주 하세요
  • 「비밀번호를 저장하시겠습니까?」가 뜨면 반드시 「아니요」

5. 끝낼 때 — 이 순서를 꼭 지키세요

할 일
①네이버에서 로그아웃
②시크릿 창 모두 닫기
③내려받은 파일이 한국 컴퓨터에 남아 있으면 정리
④애니데스크 연결 종료 (창 닫기)

※ 「사용 끝났습니다」라고 따로 알릴 필요는 없습니다. 컴퓨터는 사람별로 배정되어 있어서 다음 사람을 기다리게 하지 않습니다. ①·② 로그아웃과 시크릿 창 닫기는 반드시 하세요.

로그아웃 안 하고 끊으면

다음에 그 컴퓨터를 쓰는 사람 화면에 내 계정이 그대로 열려 있습니다. 실수로 남의 계정으로 글을 쓰면 되돌릴 수 없습니다.

6. 한국 컴퓨터를 쓸 때 지킬 것

  • 내 일만 합니다. 다른 폴더를 열어보거나 파일을 지우지 않습니다
  • 나에게 배정된 컴퓨터만 씁니다. 남의 컴퓨터 주소로 접속하지 않습니다
  • 파일은 어디에 저장되나? 한국 컴퓨터에 저장됩니다. 원고나 이미지를 내 컴퓨터로 가져오려면 파일 전송 기능을 쓰거나 공용 저장소를 거칩니다
  • 한국 컴퓨터의 설정을 바꾸지 않습니다 (배경화면, 프로그램 설치, 로그인 저장 등)
  • 이상한 화면이 뜨거나 잘 모르겠으면 손대지 말고 담당자에게 연락

7. 안 될 때

이런 경우이렇게 해보세요
주소를 넣어도 연결이 안 된다한국 컴퓨터가 꺼져 있거나 인터넷이 끊긴 것입니다. 바이버로 담당자에게 연락
「연결 대기 중」에서 안 넘어간다인터넷 확인 → 애니데스크 껐다 켜기 → 다시 시도
비밀번호가 틀리다고 나온다담당자에게 확인. 여러 번 시도하지 마세요
끝까지 접속이 안 된다미얀마 컴퓨터로 네이버에 접속하지 마세요. 담당자에게 알리고 네이버가 필요 없는 일(원고 작성, 카드뉴스 만들기)을 먼저 합니다
화면이 아주 느리다화질 설정을 「속도 우선」으로 변경
연결이 자꾸 끊긴다인터넷 문제입니다. 글은 수시로 임시저장하고 다시 연결
설치가 안 된다관리자 권한 문제일 수 있습니다. 담당자에게 연락
10분 규칙

혼자 10분 넘게 안 되면 바이버로 도움을 요청하세요. 붙잡고 있는 게 손해입니다.

8. 보안

  1. 한국 컴퓨터 주소와 비밀번호를 외부에 알려주지 않습니다.
  2. 모르는 사람이 내 컴퓨터로 접속을 요청하면 무조건 거절합니다.
    애니데스크는 사기에도 자주 쓰입니다. "은행입니다", "마이크로소프트입니다" 하면서 접속을 요구하면 100% 사기입니다.
  3. 한국 컴퓨터에서 로그인할 때는 반드시 시크릿 창
  4. 비밀번호를 브라우저에 저장하지 않습니다
  5. 자리를 비울 때는 연결을 끊습니다

담당자용 메모

  • ★ 한국 컴퓨터가 켜져 있어야 접속됩니다. 미얀마 근무는 한국 시간 10:30~19:30인데 한국 퇴근은 18:00입니다 — 퇴근할 때 PC를 끄지 말고 두어야 합니다. 절전모드도 풀어두세요.
  • 토요일도 미얀마는 한국 시간 10:30~14:30에 근무합니다. 한국은 쉬는 날이라 PC를 켜둔 채로 퇴근해야 토요일에 쓸 수 있습니다.
  • ★ PC 4~5대에 미리 설치하고 무인 접속 비밀번호까지 설정해두기로 한 상태입니다. 출국 전에 대수 확정 → 설치 → 무인 접속 설정 → 인원별 배정표 작성까지 끝내세요. 1인 1대로 배정해야 「누가 쓰는 중」 확인이 필요 없어집니다.
  • ★ 애니데스크가 지금은 예비 수단이 아니라 기본 작업 방식입니다 (네이버 서버 불안정 → 고정 IP로도 보호조치 발생). 교육에서도 이 순서로 가르칩니다. 고정 IP로 되돌릴 시점은 담당자가 판단해서 공지해야 합니다.
  • 한국 PC 주소·비밀번호는 계정시트 「애니데스크」 시트에 정리합니다.
  • 애니데스크 무료 버전은 개인 사용 기준입니다. 상시 업무용이면 라이선스를 확인하세요.

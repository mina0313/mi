DAY 7 · 9월 23일 (수) · ★ 하루 2편

혼자 하루 2편 + 피드백

가르치지 않습니다. 혼자 2편을 발행하고 피드백을 받는다

★ 오늘도 처음부터 — 이제 새로 배우는 건 없습니다

배우는 날이 아니라 「일하는 날」입니다

①~⑤를 혼자 처음부터 끝까지 돌립니다. 그것도 하루에 2편.

트레이너는 가르치지 않습니다. 막힐 때만 도와주고, 끝난 뒤에 피드백만 줍니다.

순서단계오늘
①통검표 확인 및 수정혼자
②키워드 선정 + 제목혼자
③원고 쓰기 (생성기 3줄 → 다듬기)혼자
④사진 고르기 + 카드뉴스혼자
⑤발행 → 확인 → 보고혼자

※ 이 한 바퀴를 하루에 두 번 돕니다. 실무가 그렇기 때문입니다.

오늘의 목표

  1. 키워드부터 발행까지 도움 없이 한 바퀴를 돈다
  2. 그 한 바퀴를 하루에 두 번 — ★ 2편 발행
  3. 어제 받은 피드백을 오늘 글에 반영한다
오늘의 규칙: 가르치지 않습니다

막혀도 바로 답을 주지 마세요. "그거 어느 자료에 있었죠?"로 되돌려 보냅니다. 어디서 막히는지가 오늘 알아내야 할 것입니다. 여기서 막히는 사람은 귀국 후에도 막힙니다.

진행 흐름

  1. 어제 2편 피드백어제 올린 글을 같이 보고 고칠 것 1가지씩만 말해준다
  2. ①~⑤ 1편째통검표 → 키워드 → 원고 → 카드뉴스 → 발행. 혼자
  3. 중간 보고발행 전에 담당자 확인 (익숙해지기 전까지)
  4. ①~⑤ 2편째같은 한 바퀴를 한 번 더. 1편째보다 빨라야 합니다
  5. 발행 간격 두기두 편을 몰아 올리지 않기 — 1~2시간
  6. 피드백오늘 2편에서 나온 지적을 내일 반영하도록 정리

혼자 할 순서 — 이것만 알려주세요

순서하는 일어디 보면 되나
①키워드 고르기브랜드 통합시트 「통검표」 → 기준 5가지
②겹침 확인키워드 배정표
③메인·서브 키워드 + 제목 뽑기GPT에게 제목 10개 받아 1개 고르기 — 키워드는 맨 앞
④원고 뽑기브랜드 원고 생성기에 3줄 입력 (메인/서브/제목)
⑤다듬기 · 사실 확인AI 티 지우기 · 사실 확인 · 한국어 감수
⑥사진 고르기 + 카드뉴스 회사 사진 폴더 → 미리캔버스 (장수 = 원고 문단 수)
⑦중간 보고원고 + 카드뉴스를 담당자에게 보내 확인
⑧발행 → 확인 → 보고확인 5단계 → 바이버에 링크 보고 (2편은 1~2시간 간격)
중간 점검은 ②에서 한 번만

키워드를 잘못 고르면 그날 원고가 통째로 헛일이 됩니다. 키워드까지만 확인해주고, 그다음부터는 손대지 마세요.

오늘 하는 일

  1. ① 통검표 확인 및 수정 → 아직 안 쓴 키워드 선정 + 이유 3줄
  2. ② 배정표 대조 → 메인·서브 키워드 + GPT로 제목 10개 받아 1개
  3. ③ 생성기에 3줄 입력 → 초안 → 다듬기 · 사실 확인
  4. ④ 사진 고르기 + 카드뉴스 (장수 = 원고 문단 수)
  5. ⑤ 중간 보고 → 발행 → 확인 5단계 → 보고
  6. ★ 위 한 바퀴를 한 번 더 — 2편째 (발행은 1~2시간 간격)
  7. 제출: 발행 링크 2개 + 「어제 피드백을 어디에 반영했는지」 한 줄
피드백 반영이 오늘의 핵심입니다

어제 받은 지적을 2편에서 어떻게 고쳤는지 말하게 하세요. 같은 지적이 또 나오면 그건 안 들은 겁니다. 같은 지적이 두 번 나오지 않게 하는 게 이 교육의 목표입니다.

트레이너 메모

  • 참는 날입니다. 답을 알려주고 싶어도 참으세요. 오늘 대신 해주면 귀국 후에 아무것도 안 돌아갑니다.
  • 막히는 지점을 사람별로 적어두세요. 그게 내일 수료 기준표와 다음 달 과제가 됩니다.
  • 대신 "자료 어디에 있는지"는 알려줘도 됩니다. 찾는 법을 익히는 것도 실력입니다.
  • 속도 차이가 크게 벌어집니다. 빠른 사람에게는 카드뉴스 문장까지 미리 쓰게 하세요.
  • 오늘 원고와 사진을 못 끝내면 내일 발행이 안 됩니다. 마감 시간을 정해서 알려주세요.

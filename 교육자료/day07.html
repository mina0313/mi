DAY 7 · 9월 23일 (수) · ★ 하루 2편

혼자 하루 2편 + 피드백

가르치지 않습니다. 혼자 2편을 발행하고 피드백을 받는다

★ 오늘도 처음부터 — 이제 새로 배우는 건 없습니다

배우는 날이 아니라 「일하는 날」입니다

①~⑦을 혼자 처음부터 끝까지 돌립니다. 그것도 하루에 2편.

트레이너는 가르치지 않습니다. 막힐 때만 도와주고, 끝난 뒤에 피드백만 줍니다.

순서단계오늘
①어제 발행한 글 노출 체크
통검표를 열어 어제 올린 글이 검색에 나오는지 확인·기록		혼자
②전체 메인 키워드 점검
등급 · 검색량이 바뀐 게 있는지 확인하고 수정		혼자
③메인 · 서브 키워드 선택
★ 여기서 확인받고 넘어갑니다		혼자
④제목 만들기
★ 여기서 확인받고 넘어갑니다		혼자
⑤원고 만들기
★ 여기서 확인받고 넘어갑니다		혼자
⑥카드뉴스 만들기
★ 여기서 확인받고 넘어갑니다		혼자
⑦발행 (애니데스크)
발행 → 확인 → 링크 보고		혼자

※ 이 한 바퀴를 하루에 두 번 돕니다. 실무가 그렇기 때문입니다.

오늘의 목표

  1. 키워드부터 발행까지 도움 없이 한 바퀴를 돈다
  2. 그 한 바퀴를 하루에 두 번 — ★ 2편 발행
  3. 어제 받은 피드백을 오늘 글에 반영한다
오늘의 규칙: 가르치지 않습니다

막혀도 바로 답을 주지 마세요. "그거 어느 자료에 있었죠?"로 되돌려 보냅니다. 어디서 막히는지가 오늘 알아내야 할 것입니다. 여기서 막히는 사람은 귀국 후에도 막힙니다.

진행 흐름

  1. 어제 2편 피드백어제 올린 글을 같이 보고 고칠 것 1가지씩만 말해준다
  2. ①~⑦ 1편째노출 체크 → 키워드 점검 → 키워드·제목 → 원고 → 카드뉴스 → 발행. 혼자
  3. 중간 보고발행 전에 담당자 확인 (익숙해지기 전까지)
  4. ③~⑦ 2편째같은 한 바퀴를 한 번 더. ①②는 아침에 한 번만 하므로 키워드 선택부터 시작합니다
  5. 발행 간격 두기두 편을 몰아 올리지 않기 — 1~2시간
  6. 피드백오늘 2편에서 나온 지적을 내일 반영하도록 정리

혼자 할 순서 — 이것만 알려주세요

순서하는 일어디 보면 되나
①어제 글 노출 체크 통검표 → 어제 올린 글의 키워드를 검색해보고 기록
②메인 키워드 점검 통검표 등급 · 검색량 변동 확인 (칸 안의 내용만 수정)
③메인 · 서브 키워드 선택 기준 5가지 + 키워드 배정표로 겹침 확인
④제목 만들기 GPT에게 제목 10개 받아 1개 — 키워드는 맨 앞
⑤원고 만들기 생성기에 3줄 입력 → 초안 → 다듬기 · 사실 확인
⑥카드뉴스 만들기 회사 사진 폴더 → 미리캔버스 (장수 = 원고 문단 수)
⑦발행 → 확인 → 보고 확인 5단계 → 바이버에 링크 보고 (2편은 1~2시간 간격)
확인은 ③④⑤⑥ 네 번 — 오늘은 「OK / 다시」만 말해주세요

실무에서는 네 단계마다 확인을 받습니다. 오늘도 똑같이 받게 하되, 고쳐주지는 마세요. 「OK」 또는 「다시」와 이유 한 줄만 주고 본인이 고치게 합니다.

특히 ③ 키워드는 잘못 고르면 그날 원고가 통째로 헛일이 됩니다 — 여기만 조금 더 봐주세요.

★ 오늘은 단계마다 걸린 시간을 재게 하세요

내일(DAY 8) 사람별 「최대 시간」을 정합니다. 그러려면 실제로 몇 분 걸렸는지가 필요합니다. 시작·끝 시각만 적게 하면 됩니다 — 정확하지 않아도 됩니다.

④ 제목____________

※ 목업을 만드는 브랜드(퍼스트디자인 · 하오디자인)는 ⑥이 길게 나옵니다. 정상입니다 — 그대로 적게 하세요.

오늘 하는 일

  1. ①② 노출 체크 · 메인 키워드 점검
  2. ③ 아직 안 쓴 키워드 선정 + 이유 3줄 · 배정표로 겹침 확인 → 확인
  3. ④ GPT로 제목 10개 받아 1개 → 확인
  4. ⑤ 생성기에 3줄 입력 → 초안 → 다듬기 · 사실 확인 → 확인
  5. ⑥ 카드뉴스 만들기 — 사진 고르기 포함 (장수 = 원고 문단 수) → 확인
  6. ⑦ 발행 → 확인 5단계 → 바이버 보고
  7. ★ ③~⑦을 한 번 더 — 2편째 (발행은 1~2시간 간격)
  8. ★ 단계별 걸린 시간 적기 — 내일 최대 시간을 정하는 데 씁니다
  9. 제출: 발행 링크 2개 + 「어제 피드백을 어디에 반영했는지」 한 줄
피드백 반영이 오늘의 핵심입니다

어제 받은 지적을 2편에서 어떻게 고쳤는지 말하게 하세요. 같은 지적이 또 나오면 그건 안 들은 겁니다. 같은 지적이 두 번 나오지 않게 하는 게 이 교육의 목표입니다.

트레이너 메모

  • 참는 날입니다. 답을 알려주고 싶어도 참으세요. 오늘 대신 해주면 귀국 후에 아무것도 안 돌아갑니다.
  • 막히는 지점을 사람별로 적어두세요. 그게 내일 피드백과 다음 달 보완 항목이 됩니다.
  • 대신 "자료 어디에 있는지"는 알려줘도 됩니다. 찾는 법을 익히는 것도 실력입니다.
  • 속도 차이가 크게 벌어집니다. 빠른 사람에게는 카드뉴스 문장까지 미리 쓰게 하세요.
  • 오늘 원고와 사진을 못 끝내면 내일 발행이 안 됩니다. 마감 시간을 정해서 알려주세요.

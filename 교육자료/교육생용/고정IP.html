고정 IP 접속 방법

IP가 안정된 뒤에 쓰는 방법입니다 — 지금은 애니데스크로 작업합니다

★★ 먼저 읽으세요 — 지금은 애니데스크로 작업합니다

지금 네이버 서버가 불안정합니다. 고정 IP를 제대로 켜고 접속해도 보호조치가 걸려서 계정이 잠기는 일이 생기고 있습니다.

그래서 당분간 네이버 작업은 애니데스크로 한국 컴퓨터에 접속해서 합니다. → 애니데스크 매뉴얼

이 문서는 IP가 안정되어 담당자가 「고정 IP로 돌아가도 된다」고 알려줄 때 보는 매뉴얼입니다. 그 연락을 받기 전까지는 혼자 판단해서 고정 IP로 작업하지 마세요.

왜 켜야 하나요?

고정 IP 프로그램을 켜면 내 컴퓨터가 한국에서 인터넷을 쓰는 것처럼 됩니다. 이유는 3가지입니다.

  1. 계정을 지키기 위해 — 네이버는 한국에서 쓰는 서비스입니다. 해외에서 로그인하면 추가 인증을 요구하거나 로그인이 막힐 수 있습니다.
  2. 계정이 잠기지 않게 — 같은 계정이 오늘은 한국, 내일은 다른 나라에서 접속되면 네이버가 이상한 접속으로 판단합니다.
  3. 제대로 보기 위해 — 검색 결과는 접속 위치에 따라 다르게 나옵니다. 우리는 한국 사람이 보는 화면을 봐야 판단이 맞습니다.
한 줄로 기억하세요

네이버를 켜기 전에 고정 IP를 먼저 켠다.
검색 조사 · 로그인 · 글 발행 · 키워드 도구 — 전부 해당됩니다.

1. 준비 (처음 한 번만)

우리 회사는 「고정 IP」를 씁니다

아무 VPN이나 쓰는 게 아니라, 회사가 계약한 한국 고정 IP를 씁니다. 사람마다 쓰는 아이디와 IP 주소가 정해져 있습니다.

내 IP가 매번 똑같아야 네이버가 「같은 사람이 계속 쓰는 계정」으로 인식합니다. IP가 왔다 갔다 하면 계정이 위험해집니다.

서비스____________ (회사 지정)
내 아이디____________ (담당자가 배정)
내 IP 주소______.______.______.______ ★ 반드시 적어두세요. 매번 이 숫자를 확인합니다
내려받는 곳 / 접속 방법____________________
  1. 회사가 알려준 곳에서 프로그램을 내려받아 설치합니다
  2. 「이 앱이 변경할 수 있도록 허용하시겠습니까?」 → 예
  3. 회사 계정으로 로그인합니다
아무 VPN이나 설치하지 마세요

인터넷에 있는 무료 VPN은 내가 하는 일을 다른 사람이 볼 수 있게 만드는 것도 있습니다. 회사가 알려준 프로그램만 쓰세요.

[스크린샷 넣을 자리 — 로그인 화면]

2. 접속하기 (매일 하는 일)

  1. 고정 IP 프로그램을 실행한다컴퓨터를 켜면 가장 먼저
  2. 서버 목록에서 「한국」을 고른다다른 나라를 고르면 안 됩니다
  3. 연결 버튼을 누른다「연결됨 / Connected」로 바뀔 때까지 기다립니다
  4. 진짜 연결됐는지 확인한다아래 3번 — 이 단계를 빼먹으면 안 됩니다
  5. 그다음에 네이버를 연다순서가 바뀌면 안 됩니다

[스크린샷 넣을 자리 — 서버 선택 / 연결됨 화면]

3. 연결됐는지 확인하는 법 (제일 중요)

프로그램에 「연결됨」이라고 나와도 실제로는 안 되어 있는 경우가 있습니다. 매번 눈으로 확인하세요.

  1. 인터넷 창을 새로 엽니다
  2. 네이버에서 내 아이피 를 검색합니다
  3. 화면에 나온 IP가 내게 배정된 IP 주소와 똑같은지 숫자를 봅니다
이렇게 나오면 정상이러면 안 됩니다
내 IP = 배정받은 IP와 동일, 위치 대한민국 → 작업 시작 숫자가 다르다 / 위치가 미얀마 → 작업 멈추고 다시 연결
「한국이면 됐다」가 아닙니다

숫자가 내 IP와 정확히 같아야 합니다. 한국 IP라도 다른 번호면 안 됩니다. 그래서 내 IP 주소를 종이에 적어두고 매일 대조하세요.

습관으로 만들기

아침에 컴퓨터를 켜면 → 고정 IP 연결 → 내 아이피 확인 → 그다음 일 시작. 3초면 됩니다. 이걸 안 해서 생기는 문제가 훨씬 큽니다.

4. 작업 중에 지킬 것

  • 작업이 끝날 때까지 끄지 않습니다.
  • 인터넷이 끊겼다가 다시 연결되면 고정 IP도 끊어져 있을 수 있습니다. → 글을 저장하고 → 고정 IP 다시 연결 → IP 확인 → 그다음 계속
  • 정전이 잦습니다. 글을 쓸 때는 수시로 저장하세요. (블로그 에디터의 임시저장 사용)
  • 퇴근할 때는 네이버에서 로그아웃하고 고정 IP 프로그램을 끕니다.
  • 애니데스크로 한국 컴퓨터에 접속해서 작업할 때는, 로그인을 「시크릿 창」에서 합니다. → 애니데스크 매뉴얼 4번
절대 하면 안 되는 것
  • 연결을 끈 채로 네이버에 로그인하기
  • 연결을 끈 채로 글 발행하기
  • 남에게 배정된 아이디·IP로 접속하기
  • 한 계정을 여러 사람이 각자 다른 곳에서 쓰기
실제로 있었던 일 — 이거 하나만 기억하세요

2026년 3월 10일, 고정 IP를 거치지 않고 현지 IP로 접속한 블로그 계정이 네이버 보호조치를 받았습니다. (퍼스트마케팅컴퍼니 계정 / 접속국가가 그대로 기록됨)

네이버는 접속 국가와 IP를 전부 기록합니다. 한 번 실수하면 그 계정은 오래 못 씁니다. 「오늘만 잠깐」이 안 되는 이유입니다.

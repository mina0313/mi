원고까지 반복 + 사진·카드뉴스

오늘 새로 배우는 것은 「사진 고르기 + 카드뉴스」입니다

퍼스트디자인 · 하오디자인은 인쇄물이 결과물이라 목업을 자주 씁니다 → 프리픽에서 받습니다.

6. ★★ 절대 쓰면 안 되는 것 — 여기가 오늘 제일 중요합니다

구글·네이버에서 검색해서 나온 사진은 절대 안 됩니다

예외가 없습니다. 검색 결과에 나온다고 써도 되는 사진이 아닙니다.

  • 구글 이미지 검색해서 다운로드 — ✕
  • 네이버 이미지 · 블로그 · 카페에서 저장 — ✕
  • 경쟁사·다른 회사 홈페이지 사진 — ✕
  • 워터마크가 박힌 사진 / 다른 브랜드 로고·제품이 보이는 사진 — ✕
  • 연예인·유명인 사진 / 동의 없이 인물이 알아볼 수 있게 나온 사진 — ✕
  • 출처를 모르는 사진 — ✕

저작권 문제는 회사가 돈으로 물어내는 일이 됩니다. "몰랐다"가 통하지 않습니다. 블로그 계정도 같이 위험해집니다.

강의 노트 — 마지막: 카드뉴스 만들기

8. 카드뉴스는 왜 만드나

블로그 글은 길어서 다 안 읽습니다. 카드뉴스는 그 글의 핵심만 그림으로 보여주는 것입니다. 우리 회사는 글 + 사진·카드뉴스를 한 세트로 올립니다.

기준 한 줄

"카드 한 장은 3초 안에 무슨 말인지 알아야 합니다. 3초 안에 못 읽으면 글자가 많은 겁니다."

★ 방금 고른 사진이 여기에 들어갑니다

사진 고르기와 카드뉴스는 따로가 아닙니다. 조금 전에 고른 사진은 카드뉴스에 넣으려고 고른 것입니다.

앞으로 실무에서는 둘을 한 번에 합니다 — 카드뉴스를 몇 장 만들지 정하고 → 그 장수만큼 사진을 고르고 → 바로 만듭니다.

사진에도 같은 규칙이 그대로 적용됩니다 — 구글·네이버에서 검색해서 나온 사진은 카드뉴스에도 절대 넣지 않습니다. 회사 사진 폴더 / 클립아트코리아 / 프리픽(목업) / GPT로 만든 이미지만 씁니다.

  3. 템플릿 검색 → 요소 · 텍스트 · 배경 · 업로드 메뉴 위치 확인
왕관 표시 = 유료 요소

유료 요소를 쓰면 다운로드할 때 워터마크가 생기거나 결제를 요구합니다. 작업 다 해놓고 못 내려받는 일이 자주 생기니, 고르는 순간에 왕관이 있는지 보게 하세요.

템플릿 고르는 법

  • 내가 쓸 글자 양과 비슷한 템플릿 — 글자 칸이 부족하면 다 망가집니다
  • 화려한 것보다 여백이 많은 것이 안전합니다
  • 한 세트는 같은 템플릿으로
  • 고르는 데 5분 제한 — 여기서 시간이 제일 많이 샙니다

10. 몇 장 만드나 — 원고의 문단 갯수에 맞춥니다

★ 글 길이가 아니라 「문단 수」로 정합니다

원고의 문단(소제목) 하나 = 카드 한 장. 그래서 매번 거의 비슷한 장수가 나옵니다.

글이 짧다고 장수를 줄이지 않습니다. 장수가 들쭉날쭉하면 브랜드 느낌이 흐트러지고, 적게 만든 글은 그만큼 덜 읽힙니다.

기본은 5장입니다. 문단이 더 많은 글이면 그만큼 늘립니다 (절차 안내 글은 7장 이상이 되기도 합니다 — 윈차이나·레드트랜스에 자주)

장역할넣을 내용분량
1표지제일 궁금한 것을 질문으로. 「카탈로그 제작비, 왜 다를까?」15자 이내
2문제독자가 겪는 어려움. 「업체마다 견적이 몇 배씩 차이 납니다」2줄
3해결기준·방법. 「페이지 수 / 촬영 포함 / 인쇄 포함, 이 3가지로 갈립니다」3줄
4근거실제 사례나 예시 (방금 고른 사진 활용)2줄
5마무리한 줄 정리 + 브랜드명 + 문의 방법2줄

※ 위는 하오디자인 예시입니다. 3번 「해결」 칸이 브랜드마다 달라집니다 — 하오팩토리 「재질 / 크기 / 실내외」, 하오스튜디오 「컷 수 / 기획 포함 / 촬영 포함」, 윈차이나 「비자 종류 / 체류 기간 / 필요 서류」, 레드트랜스 「언어 / 공증 포함 / 아포스티유 포함」.

디자인보다 문장이 먼저

미리캔버스를 열기 전에 카드에 넣을 문장을 다 쓰게 하세요 (종이·메모장 아무거나). 도구를 먼저 열면 예쁜 템플릿 고르다가 시간을 다 씁니다.

11. 디자인 4규칙 — 이것만 지키면 됩니다

규칙내용
①글자 크기 3단계큰 제목 / 중간 설명 / 작은 부가정보. 딱 3가지만
②색은 3개까지배경 1 + 글자 1 + 강조 1. 강조색은 정말 중요한 한 곳에만
③여백 남기기가장자리에 글자를 붙이지 않기. 초보는 채우고 싶어 합니다 — 참으라고 하세요
④줄 맞추기글자·사진의 왼쪽 끝을 맞춥니다. 하나만 어긋나도 어설퍼 보입니다
확인법

완성한 카드를 50%로 축소해서 보기 — 멀리서 봤을 때 제목이 제일 먼저 읽히면 성공입니다.

글꼴 · 브랜드 톤

  • 한 세트에 글꼴 2개까지 — 제목용(두꺼운 것) + 본문용. 손글씨체·장식체 금지
  • 줄바꿈을 단어 중간에서 하지 않기 — 「카탈로 / 그 제작」 ✕ → 「카탈로그 / 제작」 ○
  • 글자가 안 들어가면 글꼴을 줄이지 말고 문장을 줄입니다
  • 브랜드별 성격 — 하오스튜디오는 사진이 주인공, 하오팩토리는 설치 완료 사진, 하오디자인·퍼스트디자인은 정돈된 느낌, 윈차이나·레드트랜스는 읽기 쉬움 우선
  • 정한 색·글꼴은 메모에 남기고 미리캔버스에 내 템플릿으로 저장
★ 「내 템플릿으로 저장」이 나중에 속도를 결정합니다

내일부터 하루 2편이 기준입니다. 카드뉴스도 그만큼 필요합니다. 매번 템플릿을 새로 고르면 절대 못 합니다.

오늘 만든 걸 「내 템플릿」으로 저장해두고, 다음부터는 문장만 갈아 끼웁니다. 오늘 반드시 저장하는 것까지 확인하세요.

12. 내보내기

  • 다운로드 → JPG (웹용), 전체 페이지 한 번에
  • 파일명은 사진과 같은 규칙 — 날짜_브랜드명_메인키워드 + 장 번호
    20260921_하오스튜디오_상세페이지제작_카드01.jpg ~ _카드05.jpg
    미리캔버스가 자동으로 붙이는 이름(제목 없는 디자인_01)을 그대로 두지 마세요
  • 내려받은 뒤 번호 순서가 맞는지 확인 — 순서가 섞이면 글이 말이 안 됩니다
  • 워터마크가 있으면 유료 요소가 섞인 것 → 해당 요소 교체
  • 미리캔버스 원본은 지우지 않습니다 — 다음에 수정해서 재사용

오늘 하는 일

  1. ①②③ 혼자 돌리기 — 통검표 확인 → 키워드·제목 → 원고 초안
  2. 짝의 초안을 읽고 AI 티 문장 5개 찾아서 표시해주기 (서로 교환)
  3. 내 초안을 최종본으로 다듬기 — AI 티 지우기 · 사실 확인 · 한국어 감수
  4. 카드 문장부터 — 원고 문단 수만큼 장수를 정하고, 각 장에 넣을 문장을 먼저 적기
  5. 회사 사진 폴더에서 정한 장수만큼 사진 고르기 + 「고른 이유」 한 줄씩
  6. 미리캔버스 1080×1080 — 표지 1장 같이, 나머지 각자
  7. 4규칙으로 고치기 → JPG 내보내기
    파일명 날짜_브랜드명_메인키워드 규칙대로 바꾸기 — 순서 번호까지 확인
  8. ★ 「내 템플릿」으로 저장 — 내일부터 문장만 갈아 끼웁니다
오늘 끝나면 이 상태

원고 최종본 1편 + 카드뉴스 1세트. 내일 발행만 배우면 바로 올릴 수 있습니다.

트레이너 메모

  • 고칠 것은 한 사람당 1개만 말하세요. 세 개 말하면 하나도 안 고쳐집니다.
  • 짝 검토(서로 바꿔 읽기)는 한국어 실력 차이가 있어도 잘 작동합니다. 잘하는 사람이 설명하면서 두 번 배웁니다.
  • 사진은 각자 찾게 합니다. 골라주지 마세요 — 다 고른 뒤에 왜 골랐는지만 확인하면 됩니다.
  • ★ 고른 사진의 출처를 한 명씩 직접 물어보세요. "이건 어디서 가져왔어요?" — 검색해서 가져온 게 하나라도 나오면 그 자리에서 다시 설명합니다. 여기서 대충 넘어가면 나중에 사고가 납니다.
  • 저작권은 겁을 주는 게 맞습니다. "회사가 돈을 물어냅니다"까지 말하세요.
  • ★ 클립아트코리아·프리픽 로그인을 첫날에 같이 확인시키세요. 대안이 실제로 열려야 「검색하지 마세요」가 지켜집니다.
  • 프리픽은 「목업」 때만이라고 선을 그어주세요 — 안 그러면 인물·배경 사진까지 프리픽에서 받아옵니다. 하오스튜디오·하오팩토리는 회사 사진 폴더의 실사가 훨씬 강합니다.
  • 내일 발행합니다. 오늘 원고와 카드뉴스를 못 끝내면 내일이 밀립니다 — 다듬기에 너무 오래 잡혀 있지 않게 관리하세요.

목업 만들기 — 프리픽(Freepik)

퍼스트디자인 · 하오디자인에서 카탈로그·브로슈어 작업물을 실제 인쇄물처럼 보이는 사진으로 만드는 방법입니다

목업이 뭔가요?

우리가 만든 디자인 파일을 실제로 인쇄해서 책상에 놓은 것처럼 합성한 사진입니다.

왜 필요한가

디자인 파일을 그대로 올리면 화면 캡처처럼 보입니다. 목업을 쓰면 「실제로 만들어 본 결과물」로 보입니다 — 카탈로그·브로슈어·명함처럼 인쇄물을 만드는 브랜드는 이게 곧 실력 증명입니다.

쓰는 브랜드 퍼스트디자인 · 하오디자인 — 인쇄물을 만드는 브랜드
안 쓰는 브랜드 하오스튜디오 · 윈차이나 등 — 실제 촬영 사진이나 일반 이미지를 씁니다
어디에 쓰나 ⑥ 카드뉴스를 만들 때 들어가는 사진
어디서 만드나 프리픽(freepik.com) — 계정은 담당자에게 받으세요
★ 시간이 더 걸립니다 — 그게 정상입니다

목업을 만드는 날은 ⑥ 카드뉴스 단계가 30분 정도 더 걸립니다. 느린 게 아니라 일이 하나 더 있는 것입니다.

그래서 최대 시간을 사람마다 다르게 정합니다 — 같은 시간을 주면 매일 늦는 사람이 됩니다.

시작하기 전에

목업 안에 들어가는 이미지도 규칙은 똑같습니다

우리가 만든 작업물만 넣습니다. 구글·네이버에서 검색한 사진을 목업에 끼워 넣는 것은 안 됩니다.

순서 — 8단계

1. 프리픽에서 목업 찾기

  1. 검색창에 만들 인쇄물 이름을 넣습니다 「카탈로그」 · 「브로슈어」 · 「명함」 처럼. 한글로 검색해도 나옵니다
  2. 왼쪽 All Images 를 눌러 Mockups 를 선택 이걸 안 하면 목업이 아닌 일반 이미지가 섞여 나옵니다
  3. 위쪽 Editable online 을 눌러 켭니다 ★ 이게 제일 중요합니다. 안 켜면 편집이 안 되는 목업이 섞여 나와서, 골라놓고 나서 못 쓰게 됩니다
① 검색 → ② All Images → ③ Mockups → ④ Editable online

2. 템플릿 고르고 Edit

  1. 마음에 드는 목업을 클릭합니다 우리 작업물과 비슷한 형태인지 보세요 — 펼친 책 / 표지만 / 여러 장
  2. 오른쪽 Edit 버튼을 누릅니다 새 창이 열립니다
★ Edit with AI 밖에 없으면 그 템플릿은 못 씁니다

오른쪽에 Edit 버튼이 없고 Edit with AI 만 있으면 뒤로 가서 다른 목업을 고르세요. 붙잡고 있지 마세요.

1단계에서 Editable online 을 켜두면 이런 게 거의 안 나옵니다.

오른쪽 Edit — 「Edit with AI」만 있으면 사용 불가

3. 이미지 넣기

  1. 이미지를 넣고 싶은 페이지 위치를 클릭합니다 표지면 표지를, 펼친 면이면 그 면을. 클릭하면 작은 창이 뜹니다
  2. Add image 를 눌러 파일을 선택합니다 미리 준비해둔 우리 작업물을 올립니다
① 넣을 위치 클릭 → ② Add image

4. Edit element 누르기

  1. 이미지가 들어가면 Edit element 를 누릅니다 여기서 위치와 크기를 맞춥니다. 이걸 안 하면 이미지가 어긋난 채로 남습니다
Add image 아래 Edit element

5. Fill 누르고 점선에 맞추기

  1. Fill 을 누릅니다 이미지가 영역을 꽉 채우게 됩니다
  2. 분홍색 점선에 맞게 이미지를 드래그합니다 점선 안쪽이 실제로 보이는 부분입니다. 점선 밖은 잘려 나갑니다 — 중요한 글자나 로고가 점선 밖으로 나가지 않게 하세요
Fill → 분홍 점선에 맞게 드래그

6. Save changes

  1. 조정이 끝나면 오른쪽 위 Save changes 를 누릅니다 저장하지 않고 창을 닫으면 처음부터 다시 해야 합니다
오른쪽 위 Save changes

7. 배경색 바꾸기 (선택)

  1. 배경을 클릭하면 색상 팔레트가 나옵니다 브랜드 색이나 카드뉴스 배경과 어울리는 색으로. 안 바꿔도 됩니다
고민하지 마세요

배경색은 있으면 좋은 것이지 필수가 아닙니다. 여기서 시간을 오래 쓰면 그날 발행이 밀립니다 — 기본 회색 그대로도 충분합니다.

배경 클릭 → 색상 팔레트

8. Export 로 내려받기

  1. 오른쪽 위 Export 를 누릅니다 File type은 PNG 그대로
  2. Download size 슬라이더를 가운데로 옮깁니다 왼쪽 끝은 너무 작아서 흐려지고, 오른쪽 끝은 파일이 무거워집니다
  3. Download 를 누르면 끝입니다 받은 파일은 파일 이름 규칙대로 바꿔서 보관합니다
Export → PNG → 크기 가운데 → Download
파일 이름은 규칙대로

날짜_브랜드명_메인키워드
20260921_퍼스트디자인_카탈로그제작.png

막혔을 때

이런 일이 생기면이렇게 하세요
Edit 버튼이 안 보인다 Editable online 을 안 켰거나, 편집이 안 되는 목업입니다. 1단계로 돌아가 필터를 켜고 다시 고르세요
Edit with AI 만 있다 그 템플릿은 못 씁니다. 다른 목업을 고르세요
이미지가 잘려서 글자가 안 보인다 Fill 을 누른 뒤 드래그로 위치를 옮깁니다. 분홍 점선 안쪽만 보인다는 걸 기억하세요
이미지가 찌그러진다 Fill 대신 Fit 을 눌러보세요. 여백이 생기지만 비율은 유지됩니다
받은 사진이 흐리다 Download size 슬라이더가 왼쪽 끝에 있었던 것입니다. 가운데로 옮기고 다시 받으세요
저장했는데 없어졌다 Save changes 를 안 누르고 창을 닫으면 사라집니다. 조정 → 저장 → 내려받기 순서를 지키세요
10분 넘게 막혔다 바로 물어보세요. 목업 하나 붙잡고 오전을 보내면 그날 발행이 밀립니다

기억할 것 4가지

  1. Editable online 을 먼저 켠다 — 안 켜면 헛수고합니다
  2. 분홍 점선 안쪽만 보인다 — 로고와 글자를 점선 안에
  3. Save changes → Export 순서
  4. 목업은 예쁘게보다 빠르게 — 배경색·각도에 시간 쓰지 않기

담당자 메모

언제 가르치나

DAY 5(사진·카드뉴스)에서 퍼스트디자인 · 하오디자인 담당자에게만 따로 알려주세요. 다른 두 명은 그동안 카드뉴스 템플릿을 저장하게 하면 됩니다.

시간 배분에 반드시 반영하세요

목업 담당 2명은 ⑥ 카드뉴스가 30분 이상 더 걸립니다. DAY 8에 최대 시간을 정할 때 이 두 명은 다르게 잡아야 합니다. 같은 시간을 주면 그 사람은 매일 늦는 사람이 되고, 결국 대충 만들게 됩니다.

미리 확인할 것
  • 프리픽 계정이 목업 편집까지 되는지 — 무료 계정은 편집·다운로드가 막힐 수 있습니다. 출발 전에 한 번 만들어 보세요
  • 미얀마에서 프리픽 편집 화면이 뜨는지 — 무거운 페이지라 인터넷이 느리면 저장에서 실패할 수 있습니다
  • 자주 쓰는 목업 3~4개를 미리 골라두기 — 매번 검색하면 시간이 갑니다. 즐겨찾기 해두게 하세요
화면 사진 넣는 법

이 페이지에는 화면 사진 자리가 8개 준비되어 있습니다. 캡처 파일을 이미지/목업/ 폴더에 01.png ~ 08.png 이름으로 넣으면 자동으로 나옵니다. 없으면 그 자리는 그냥 비어 보입니다 — 깨진 그림으로 나오지 않습니다.

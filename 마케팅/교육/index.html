2026년 9월 16일 ~ 24일 · 8일 · 4명

메세지 블로그 현지교육

미얀마 마케터 4명에게 메세지 블로그 원고를 혼자 쓰고 발행하는 법을 가르칩니다

이 교육이 끝나면

목표는 하나입니다

담당자가 없어도 글 한 편을 혼자 처음부터 끝까지 쓰는 것.

발행은 지금 하지 않습니다. 글이 밀려 내려갔을 때 바로 올릴 재고를 쌓는 시기입니다.

★★ 생성기를 쓰지 않습니다

빈 화면에서 시작해 처음부터 끝까지 직접 씁니다. 초안을 받아서 고치는 방식이 아닙니다.

기준은 이 원고 한 편입니다. 8일 동안 이 글이 어떻게 만들어졌는지를 뜯어보고, 똑같은 짜임새로 쓰는 법을 배웁니다.

느립니다. 대신 사람이 쓴 글이 나옵니다. AI가 쓴 글은 누구나 5분이면 만듭니다 — 회사가 돈을 받는 이유가 여기입니다.

하루 순서 — 5단계

순서하는 일어떻게
① 키워드 확인 → 읽는 사람을 한 문장으로 배정받은 것 — 직접 고르지 않습니다
②소제목 3개 정하기 ★확인 궁금한 것 10개 → 묶기 → 3개
큰 것 → 구체적 → 돈
③본문 3덩어리 소제목마다 6단계로
질문 → 답 → 풀이 → 독자 질문 → 안 하면 생기는 일 → 정리
④★ 도입 7문단 → 마무리 → 소리 내어 읽기 ★확인 도입은 맨 마지막에 씁니다
⑤이미지 만들기 ★확인 5~8장 · 도식 1개 → 제출
★ 미얀마팀이 하는 일 / 안 하는 일
하는 일 원고 제작 — 소제목 · 본문 · 도입 · 이미지
안 하는 일 키워드 선정 — 브랜드 · 각도까지 정리해서 받습니다
노출 확인 · 배포 전략 — 다른 팀이 맡습니다
당분간 안 함 발행 — 지금은 재고를 쌓습니다. 방법은 DAY 6에 배워두고 시작 시점은 담당자가 알려줍니다

③④가 우리 일의 본체입니다. 여기에 하루의 대부분을 씁니다.

브랜드 7개 — 전원이 돌아가며 씁니다

교육 8일 전원 메세지로 배웁니다 — 4명을 같이 앉히고 한 번에 설명할 수 있습니다
배우는 것은 한 편을 제대로 쓰는 법입니다. 브랜드는 재료일 뿐입니다
실무 브랜드 7개를 전원이 돌아가며 — 메세지 · 퍼스트디자인 · 하오디자인 · 하오스튜디오 · 하오팩토리 · 레드트랜스 · 윈차이나
「내 브랜드」는 없습니다. 그날 받은 키워드가 브랜드를 정합니다
★ 브랜드가 7개여도 커리큘럼은 그대로입니다

그대로인 것 — 글의 뼈대 · 다듬는 법 · AI 티 지우기 · 이미지 · 제출. 8일 동안 배우는 게 전부 여기입니다.

바뀌는 것 — 읽는 사람 · 파는 것 · 쓸 수 있는 사례 · 사진. 이건 브랜드 자료 한 장으로 해결됩니다.

★ DAY 7에 브랜드를 한 번 바꿔서 써보게 하세요. 「뼈대는 같고 재료만 바뀐다」를 손으로 확인해야 실무에서 안 무너집니다.

★★ 담당자가 새로 떠안는 일 — 키워드에 브랜드를 붙여서

전원이 전 브랜드를 쓰면 겹치는 키워드를 나눌 사람이 없어집니다. 예전에는 담당이 달라서 자연히 나뉘었습니다.

카탈로그 · 브로슈어 · 리플렛 · 회사소개서 → 하오디자인 ↔ 퍼스트디자인
아포스티유 → 윈차이나 ↔ 레드트랜스

키워드를 줄 때 브랜드를 같이 지정해 주세요 — 「카탈로그제작 / 퍼스트디자인」 식으로. 그러면 교육생이 고민할 일이 없습니다.

★★ 원고 축적 = 재고 쌓기 — 이걸 먼저 이해시키세요

올린 글은 시간이 지나면 밀려 내려갑니다. 그 자리를 다시 잡으려면 같은 키워드로 새 글을 또 올려야 합니다. 그때 올릴 원고가 없으면 그 키워드는 비어버립니다.

지금 발행하지 않고 원고만 모으는 이유가 이것입니다. 교육생이 이걸 모르면 「왜 안 올리지」 「이거 쓸모없는 일 아닌가」가 됩니다.

그래서 같은 메인키워드로 여러 편이 정상입니다. 다만 앞 편을 베끼면 둘 다 안 올라갑니다 — 매번 새로 씁니다.
서로 다른 글이 되게 각도 8개를 넣었습니다 — 비용 / 고르는 법 / 차이 / 절차 / 준비물 / 조심할 것 / 업종별 / 사례.

키워드를 줄 때 각도까지 지정해 주시면 가장 깔끔합니다 — 「카탈로그제작 / 퍼스트디자인 / 각도 2」. 파일 이름도 20260922_퍼스트디자인_카탈로그제작_2

병원 · 법률은 메세지 안의 이야기입니다

메세지 키워드 8축 중 병원 · 법률 축이 있습니다. 이건 브랜드가 아니라 메세지가 어떤 고객에게 말하는가입니다.

그 축을 누가 맡을지는 교육이 끝난 뒤 원고를 보고 정합니다 — 규정이 있어 사실 확인이 꼼꼼한 사람이 맞습니다.

★ 메세지 이야기 — 모든 글의 뿌리

첫날에 외우게 하세요. 숫자까지

★ 운영사 경력입니다 — 메세지 운영 기간으로 쓰면 안 됩니다
한 일남에게 실험할 수 없어 자사 브랜드 10개에 직접 적용

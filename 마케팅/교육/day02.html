전체 일정 원고 쓰는 법 이미지 준비물
9월 17일 (목) · DAY 2 / 8

첫 원고 · 첫 컨펌

직접 써보고 컨펌 → 수정을 한 바퀴 돌려봅니다

매일 같은 순서

①오늘 쓸 키워드 확인메인키워드 · 각도 — 배정받습니다
②원고 쓰기소제목 3개 → 본문 → 도입 → 마무리
③★ 컨펌 → 수정★ OK 나올 때까지 반복합니다
④이미지 만들기★ 컨펌 끝난 뒤에 → 제출

★ ③이 본체입니다. 한 번에 OK가 나오는 글은 없습니다 — 고치면서 늡니다.

오늘 하는 일

  1. 키워드를 받고 어떻게 쓸지 정한다
  2. ★ 소제목 3개를 먼저 정하고 확인받는다
  3. 본문 → 도입 → 마무리 순으로 한 편을 쓴다
  4. ★ 컨펌받고 고친다 — 오늘의 핵심

1. 쓰기 전에 — 두 가지

① 어떻게 쓸까 메세지를 알리는 글인가, 정보를 주는 글인가
★ 본인이 정합니다. 회사 원고 두 갈래를 참고하세요
② 읽는 사람 한 문장으로 적고 시작합니다
「대행사를 쓰는데 효과를 모르겠는 중소기업 담당자」

2. ★ 소제목 3개부터 — 확인받고 넘어갑니다

본문부터 쓰지 않습니다. 소제목 3개가 안 나오면 아직 쓸 준비가 안 된 것입니다.

궁금한 것 10개 적기 → 묶기 → 큰 것 → 구체적 → 돈 순서 → 3개만

★ 여기서 반드시 한 번 봐주세요

소제목이 틀리면 본문을 통째로 다시 씁니다. 3개를 받아보고 OK / 다시를 주세요.

✕ 「○○의 중요성」 「○○란 무엇인가」 — ○ 「광고를 늘리기 전에 무엇이 새고 있는지부터 봐야 합니다」

3. 쓰는 순서 — 본문 → 도입 → 마무리

본문 소제목마다 5단계
상황 → 굵은 질문 → 예를 들어 → 저희는 이렇게 → 굵은 결론
도입 ★ 본문을 다 쓴 뒤에
장면 → 질문 → 인정 → 그런데 → 메세지 경험
마무리 메세지를 알리는 글이면 고정 카피 2줄 + 링크
정보 글이면 「직접 해보세요」로

★ 공백 제외 1,800자. 넘치면 소제목 하나를 통째로 뺍니다.
→ 자세한 건 원고 쓰는 법

4. ★★ 컨펌 — 오늘의 핵심

한 번에 OK가 나오는 글은 없습니다

쓴다 → 컨펌 → 고친다 → 다시 컨펌. 이게 정상이고, 고치면서 늡니다.

보낼 때 제목 · 소제목 3개 · 본문 전체를 한 번에
받는 답 어디를 왜 고쳐야 하는지
고칠 때 ★ 고친 이유를 같이 적어 다시 보냅니다
그래야 같은 지적을 두 번 안 받습니다
자주 나오는 지적

· 도입이 회사 이야기로 시작했다
· 소제목에 「중요성」 「~란」이 들어갔다
· 덩어리에 굵은 질문이 없다
· 지어낸 숫자 · 사례가 있다
· 자사 사례를 썼는데 면책 문장이 빠졌다
· 1,800자를 넘었다

완료 체크

트레이너 메모

  • ★★ 소제목 3개를 반드시 먼저 보세요. 여기가 틀리면 본문을 통째로 다시 씁니다
  • ★ 첫 컨펌은 잘한 곳을 먼저 말해주세요. 여기서 꺾이면 남은 날이 힘듭니다
  • ★ 지적은 3개까지만. 다 고치라고 하면 아무것도 안 고쳐집니다
  • 오늘 완성까지 못 가도 됩니다. 컨펌을 한 바퀴 돌려본 게 목표입니다

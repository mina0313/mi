본문 3덩어리 완성

매일 같은 순서

①오늘 쓸 키워드 확인 → 읽는 사람을 한 문장으로배정받은 것 — 직접 고르지 않습니다
②소제목 3개 정하기★ 여기서 확인받고 넘어갑니다
③본문 쓰기소제목마다 6단계로
④도입 7문단 → 마무리 → 소리 내어 읽기★ 여기서 확인받고 넘어갑니다
⑤이미지 만들기★ 확인 → 제출

1. 덩어리 3개는 길이가 비슷해야 합니다

★ 1번만 길고 3번이 짧으면 힘이 빠집니다

보통 1번을 열심히 쓰고 뒤로 갈수록 대충 합니다. 읽는 사람은 마지막에 결정하는데 거기가 부실해집니다.

덩어리마다 8~12문단 정도로 맞추세요. 한 덩어리가 너무 짧으면 5번(안 하면 생기는 일)이 빠져 있을 겁니다.

2. ★★ 사례 — 지어내면 끝입니다

기준 원고에는 「청담 모 성형외과」 사례와 전후 비교표가 들어 있습니다. 이게 글의 신뢰를 만듭니다.

우리는 확인된 것만 씁니다

숫자 하나를 지어내면 브랜드를 통째로 잃습니다. 고객이 물어보면 답할 수 없기 때문입니다.

사례가 없으면 비워두고 요청 문구를 남깁니다.

[사례 요청: 퍼스트디자인 카탈로그 전후 비교 / 숫자 확인 필요]

3. 이어 읽기 — 흐름 확인

3덩어리를 처음부터 끝까지 소리 내어 읽습니다. 이때 찾는 것 두 가지.

끊기는 곳 덩어리와 덩어리 사이가 뚝 끊기면 이어주는 한 줄을 넣습니다
같은 말 반복 세 덩어리에서 같은 설명이 또 나오면 뒤엣것을 지웁니다

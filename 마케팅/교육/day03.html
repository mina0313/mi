왜 제목에 하루를 쓰나

제목이 약하면 글 전체가 흔들립니다. 생성기는 제목을 기준으로 본문을 만들기 때문입니다.

그리고 제목은 고객이 제일 먼저 보는 것입니다.

강의 노트

1. 제목 만드는 법

  • 메인 키워드를 앞부분에
  • ★ 서브 키워드 1개도 자연스럽게 포함
  • 키워드를 나열하지 말고 하나의 문장으로 연결
  • 독자의 고민 · 메세지가 겪은 위기 · 직접 적용한 방법 중 하나로 관심을 끌기
  • 제목이 약속한 내용을 본문에서 실제로 설명하기
  • 근거 없는 성과 · 순위 · 수치를 넣지 않기

2. 대조해서 보기

✕ 밋밋한 제목○ 읽고 싶은 제목
마케팅 대행사 선택 방법 마케팅대행사, 저희 브랜드가 검색에서 사라졌을 때 바꾼 기업마케팅
병원 마케팅 완벽 가이드 병원마케팅, 광고를 끄면 사라지는 것과 병원블로그에 남는 것
변호사 마케팅의 모든 것 변호사마케팅, 광고비를 늘려도 상담이 늘지 않을 때

오른쪽에는 전부 「왜」 또는 「무슨 일이 있었는지」가 들어 있습니다.

3. ★ 제목은 여러 개 받아서 고릅니다

처음부터 하나를 잘 쓰려고 하지 마세요. 많이 받아서 고르는 게 빠릅니다.

이렇게 시킵니다

메인 키워드 : 병원마케팅 서브 키워드 : 병원블로그 읽는 사람 : 병원 원장 제목 10개만 뽑아줘. - 메인 키워드를 앞부분에, 서브 키워드도 하나 넣어서 - 하나의 문장으로 연결 - 과장·최상급·근거 없는 수치 금지

10개를 다 읽어보게 하세요. 고르는 눈이 그때 생깁니다.

4. 오늘은 두 편입니다 — 속도를 봅니다

어제 한 편을 뽑아봤으니 오늘은 두 편입니다. 2편째가 1편째보다 확실히 빨라야 정상입니다.

빨라지는 이유

매번 새로 만들지 않기 때문입니다. 제목 프롬프트를 메모장에 저장해두고, 생성기는 즐겨찾기해두세요.

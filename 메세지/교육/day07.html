DAY 7 · 9월 23일 (수)

혼자 2편 + 시간 재기

배울 건 다 배웠습니다. 혼자 처음부터 끝까지 돌립니다

★ 매일 같은 순서를 반복합니다

오늘부터 도와주지 않습니다

①~⑤를 혼자 돌립니다. 그것도 하루에 2편.

확인은 ②④⑤ 세 번 받되, 고쳐주지는 마세요. 「OK」 또는 「다시」와 이유 한 줄만 줍니다.

순서단계오늘
①오늘 쓸 키워드 확인
배정받은 것 — 직접 고르지 않습니다		혼자
②제목 만들기
★ 여기서 확인받고 넘어갑니다		혼자
③원고 만들기
생성기에 3줄 → 초안		혼자
④★ 다듬기 · 사실 확인
★ 여기서 확인받고 넘어갑니다		혼자
⑤이미지 만들기
★ 확인 → 검수에 제출		혼자

오늘의 목표

  1. 키워드를 받아 완성본까지 도움 없이 한 바퀴를 돈다
  2. 그 한 바퀴를 하루에 두 번 — ★ 완성본 2편
  3. ★ 단계별 걸린 시간을 잰다 (내일 최대 시간을 정합니다)
  4. 어제 받은 피드백을 오늘 글에 반영한다
★ 오늘은 단계마다 걸린 시간을 재게 하세요

내일 사람별 「최대 시간」을 정합니다. 시작·끝 시각만 적으면 됩니다.

12:00점심

16:00★ 시간 기록 · 피드백내일 최대 시간을 정합니다

※ 시각은 기준입니다. 막히면 그 자리에서 해결하고 그날 분량을 줄이세요 — 진도보다 이해가 먼저입니다.

혼자 할 순서 — 이것만 알려주세요

순서하는 일어디 보면 되나
①오늘 쓸 키워드 확인 배정받은 것 — 「이 사람이 뭘 궁금해할까」를 먼저 정리
②제목 만들기 10개 받아 1개 — 메인 앞 · 서브 포함
③원고 만들기 생성기에 3줄 → 초안
④★ 다듬기 · 사실 확인 지울 말 · 「저희」 · 확정 목록 대조 · 소리 내어 읽기
⑤이미지 만들기 5~8장 · 도식 1개 (저장한 템플릿에 글자만)
확인은 ②④⑤ 세 번 — 오늘은 「OK / 다시」만

고쳐주지는 마세요. 「OK」 또는 「다시」와 이유 한 줄만 주고 본인이 고치게 합니다.

특히 ④ 다듬기가 우리 일의 본체입니다 — 여기만 조금 더 봐주세요.

발행은 오늘 하지 않습니다

완성본까지만 만들어서 제출합니다. 원고를 모아두는 시기입니다.

속도를 올리는 것들 — 오늘 확인하세요

무엇을어떻게
도식 템플릿어제 저장한 것에 글자만 교체
생성기 즐겨찾기매번 찾지 않게
제목 프롬프트메모장에 저장해두고 붙여넣기
지울 말 목록옆에 띄워두고 찾아서 지우기

오늘 하는 일

  1. 어제 피드백 확인 — 오늘 어디에 반영할지 정하기
  2. ① 키워드 확인 — 「이 사람이 뭘 궁금해할까」
  3. ② 제목 10개 → 1개 → 확인
  4. ③ 초안 뽑기
  5. ④ 다듬기 · 사실 확인 → 확인
  6. ⑤ 이미지 5~8장 → 확인
  7. ★ ①~⑤를 한 번 더 — 2편째
  8. ★ 단계별 걸린 시간 적기
  9. 제출: 완성본 2편 + 「피드백을 어디에 반영했는지」 한 줄

    같은 지적이 두 번 나오지 않게 하는 게 이 교육의 목표입니다

  • 2편째가 확실히 빨라야 정상입니다. 안 빨라지면 어디서 막히는지 보세요
  • 발행은 안 합니다. 완성본까지만 — 헷갈리지 않게 다시 말해주세요

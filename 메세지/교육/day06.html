DAY 6 · 9월 22일 (화)

이미지 + 검수 · 발행 배워두기

오전에 이미지와 검수, 오후에 발행을 한 번 배워둡니다

★ 매일 같은 순서를 반복합니다

오늘로 ⑤까지 채워집니다

오전에 이미지를 배우면 하루 순서가 전부 완성됩니다.

오후에는 발행을 한 번 해봅니다. 매일 하는 일은 아니지만, 나중에 시작할 때 처음부터 배우면 늦습니다.

순서단계오늘
①오늘 쓸 키워드 확인
배정받은 것 — 직접 고르지 않습니다		복습 — DAY 2
②제목 만들기
★ 여기서 확인받고 넘어갑니다		복습 — DAY 3
③원고 만들기
생성기에 3줄 → 초안		복습 — DAY 2
④★ 다듬기 · 사실 확인
★ 여기서 확인받고 넘어갑니다		복습 — DAY 5
⑤이미지 만들기
★ 확인 → 검수에 제출		★ 오늘 새로 배웁니다

오늘의 목표

  1. 이미지를 몇 장, 어디에 넣는지 안다
  2. ★ 검색해서 나온 사진은 절대 쓰지 않는다는 걸 안다
  3. ★ 검수 기준을 알고 자기 글을 스스로 점검한다
  4. 발행하는 법을 한 번 해본다 (당분간 안 씁니다)
★ 오늘부터 검수가 붙습니다

앞으로 원고가 하루 수십 개가 되면 검수가 제일 막힙니다.

그래서 본인이 먼저 점검하고 내는 습관을 오늘부터 들입니다. 검수자가 걸러야 할 게 줄어들수록 전체가 빨라집니다.

09:00이미지 수량 · 배치5~8장 · 강한 이미지 / 약한 이미지

※ 시각은 기준입니다. 막히면 그 자리에서 해결하고 그날 분량을 줄이세요 — 진도보다 이해가 먼저입니다.

강의 노트 — 앞부분: 이미지

1. 수량과 배치

한 편에5 ~ 8장
맨 위 1장대표 이미지 — 제목 글자를 넣으세요
소제목마다 1장소제목 바로 아래
도식 1~2장과정 · 비교. 글의 무게를 만듭니다
마지막 1장상담 안내 직전

이미지를 연달아 두 장 붙이지 마세요. 사이에 글이 있어야 읽힙니다.

2. ★ 강한 이미지 / 약한 이미지

✕ 약한 이미지○ 강한 이미지
노트북 앞에 앉은 사람 사진
지구본 · 회로 그림
「AI 느낌」 이미지는 아무 말도 안 합니다		 AI 답변 화면 캡처 — 가장 강합니다
과정 도식 · 비교 도식

"예쁜 사진이 아니라 내용을 도와주는 그림을 넣습니다. 이미지 하나가 문단 하나를 대신할 수 있어야 합니다."

3. ★★ 검색해서 나온 사진은 절대 금지

여기서 사고가 나면 회사가 돈을 물어냅니다

「출처를 적으면 되지 않나요」 — 안 됩니다.

쓸 수 있는 것 — 회사 사진 폴더 / 회사가 결제한 유료 사이트 / 직접 만든 도식 / GPT로 만든 이미지

캡처 전에 가릴 것 — 계정 이름 · 이메일 · 고객사 이름 · 내부 시트 주소
가로형 · 1000px 이상 · 파일 이름 날짜_메세지_메인키워드

자료가 없으면 만들지 말고 요청하세요

없는 캡처를 만들어내지 말고 원고에 요청 문구를 남깁니다.

[이미지 요청: 퍼스트디자인의 구글 AI 개요 노출 캡처 / 검색어와 촬영일 확인 필요]

★ 오늘 꼭 하세요 — 템플릿 저장

도식 템플릿을 한 번 만들어 저장해두고 글자만 갈아 끼우세요. 매번 새로 만들면 이미지에만 한 시간이 갑니다.

강의 노트 — 가운데: 검수

4. ★ 내가 먼저 점검하고 냅니다

원고가 늘어나면 검수가 제일 막히는 자리가 됩니다. 본인이 걸러낼수록 전체가 빨라집니다.

낼 때 스스로 확인하는 것 — 가이드의 「발행 전 점검」을 그대로 씁니다.

1제목에 메인 · 서브 키워드가 들어갔는가
2인사 없이 시작했는가
3번호형 소제목이 3~5개인가
4★ 지어낸 사실 · 수치 · 사례가 없는가
5★ 15년을 메세지 운영 기간처럼 쓰지 않았는가
6★ 가격 · 견적이 들어가지 않았는가
7분량이 2,500~3,500자인가
8마무리 카피 2개 + 링크가 있는가
9소리 내어 읽었는가
제출할 때 같이 내는 것

확인이 필요한 것은 본문에서 빼고 「작성자 확인 사항」으로 따로 적습니다. 비워두지 말고 「없음」이라도 적으세요.

강의 노트 — 뒷부분: 발행 (배워만 둡니다)

5. 오늘은 한 편만 해봅니다

지금은 원고를 모으는 시기입니다. 매일 발행하지 않습니다.

다만 나중에 시작할 때 처음부터 배우면 늦어서 오늘 한 번 해봅니다.

  1. 애니데스크로 내 한국 컴퓨터에 접속
  2. 네이버 로그인 (내 계정만)
  3. 글쓰기 → 원고 붙여넣기 → 이미지 순서대로
  4. 제목 확인 → 발행
  5. PC · 모바일에서 확인 → 링크를 바이버에 보고

→ 애니데스크 매뉴얼

오늘 하는 일

  1. 완성본에 이미지 5~8장 만들어 넣기
  2. ★ 도식 1개 직접 만들기 + 템플릿으로 저장
  3. ★ 발행 전 점검 9개로 자기 글 채점
  4. 「작성자 확인 사항」 적기 (없으면 「없음」)
  5. ★ 발행 1편만 해보기 — 애니데스크로
  6. 제출: 완성본 2편 (이미지 포함)
